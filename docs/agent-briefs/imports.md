Spec: Part I §2–§3, §6 "Import and identity resolution"; Part III "Import adapters and reconciliation", "Temporal and unit rules", import acceptance tests; Part V (per-file schemas, lease-event calculations, import acceptance rules).
Owner will upload the 11 Pune files LATER; DB starts empty. Build a general safe import engine + 8 adapters keyed by schema signature (header fingerprint), not filename.
1. Migration 20261031001000–001099: import_batch (source_object_id, adapter, versions, status, counts jsonb, diff vs previous version), staged_row (sheet, row_number, raw_json, locator, status accepted/quarantined/excluded/duplicate, reason, mapped_json, target links), import_exception, adapter_mapping (per-workspace saved column maps, approved), identity_match_candidate. make_business_table.
2. Pipeline: upload to storage workspace-files/<ws>/imports/ → sha256 → source_object (same hash = no-op; same name new hash = new version + field diff) → parse read-only (exceljs/papaparse; never execute macros/formulas/external links; keep cached values + formula text) → schema-signature detection → mapping (unknown schema => quarantine batch for mapping review) → type checks → staging → matching → exception queue → validated upserts → reconciliation: raw = accepted + quarantined + deliberately excluded; separate master counts (new vs existing-linked) and duplicates.
3. Adapters (pure + unit tests on synthetic fixtures): asset_list_v1 (incl. headerless upcoming tab via approved 7-column positional map, first row is data; floor-size range → min/max + text; total area 0 → total_area_source_zero), ready_asset_v1, lease_large_v1, lease_small_v1 (shifted columns), transactions_2022_v1 (exclude subtotals), transactions_2023_v1, market_matrix_v1 (skip metadata row, unpivot, transposed rent, supply total as control, never invent 2026 supply, no summing stock), comparison_reference_v1 (reference only).
4. Lease events: lease vs lock-in distinct; expiry = edate(start, integer months) date_basis calculated_from_source_tenure; keep formula + cached value; fractional tenure → needs_review. Size rules on typed area (strict >5,000 & <200,000 configurable via workspace_setting); boundaries kept for review; <8,000 rows classified not discarded.
5. Identity: companies by legal id/verified domain + name context; group/subsidiary linked not merged; people never merged by name; buildings by alias+locality+tower/campus+coords, never collapse towers. ≥0.95 auto-link only with agreeing hard identifiers; 0.80–0.95 review; else separate. Merges via proposeChange operation 'merge'.
6. Identical re-import => zero new masters/events. entity_alias populated.
7. Call the admin kill switch (src/modules/admin/killswitch.ts assertIngestionAllowed, or check workspace.ai_paused) before processing.
8. UI /imports: batch list with reconciliation numbers, upload form, batch detail (counts, exceptions, quarantined rows, mapping review/approve, match review link/keep separate). API POST /api/v1/imports, GET /api/v1/imports/[id]/reconciliation. Job imports.process.
9. Tests: repeat & revision, headerless tab, size labels, lease chronology, historical periods, identity ambiguity.
